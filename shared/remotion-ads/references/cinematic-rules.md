# Cinematic rules

Think in **shots**, not slides. The UI is a physical subject. You are filming it with a virtual camera.

## Forbidden default

A full device, centered, same scale, for the whole video, with captions underneath.

That is a carousel. Redesign.

## Camera language

Use several of these in a 15s ad:

- extreme UI crops / macro details
- push-in, pull-out, pan
- parallax (type, device, background move at different speeds)
- 3D perspective / tilt / small rotation
- partial device framing (a corner, a bezel, UI escaping the phone)
- full-bleed UI (no device chrome)
- kinetic type larger than the product
- type behind the device, then the device moving to reveal it
- match cuts (shape, color, or motion continues across a cut)
- whip / snap zoom between scales
- split screen used once, not as a layout system
- cursor, tap, scroll as performance — not decoration
- focus / blur / light / shadow / depth

Do not keep the entire phone or window centered for the whole advertisement.

## Shot change test

Before approving the storyboard, ask of every shot:

1. Could this have come from PowerPoint, Keynote, Canva, or a screenshot carousel? If yes, redesign.
2. Is the composition meaningfully different from the previous shot (scale, angle, subject, or crop)? If no, redesign.
3. Would this frame still be interesting with all copy removed? If no, improve the cinematography.

## Pacing

A 15s performance ad usually wants 5–9 shots. Not a rule — a smell test. If you have 3 shots of the same hero phone, you are sliding.

Leave almost no dead air. Hold a result long enough to read. Cut away from explanation.

## Typography

- 2–7 word statements
- huge type
- cropped letters
- type as a layer in z-space, not a subtitle track
- one idea per shot

Avoid paragraphs, feature lists, and explanatory subtitles throughout.

## Motion style follows strategy

| Direction | Motion |
| --- | --- |
| FOMO / urgency | fast cuts, escalating scale, hard eases |
| Premium / status | slow, controlled, long push-ins |
| Chaos → calm | unstable → smooth |
| Challenge | tight, progressive |
| Feel-good | gentle, opening up |
| Demo | camera tracks the action precisely |

Do not spring everything. Spring is a taste, not a default.

## Audio

If music or SFX exist, cut on hits. Clicks, whooshes, impacts, silence before a reveal. If no audio, the picture must still work.

Do not hide weak editing under SFX.

## Product clarity

By the end, a stranger can say what the product **does**. The name can arrive late. The job cannot stay hidden.
