# Example campaign shape

A finished 15s vertical ad for a fictional local-only camera app. For structure only — do not copy the claims into a real product.

## Selected strategy

`loss-aversion` — the viewer already has thousands of photos they never open.

## Hero hook

Extreme crop of a camera-roll thumbnail grid scrolling too fast to see any face. Type, cropped: **you took them**. No logo.

## Concept

"Burial → one print." The roll is a mass. The product lifts a single frame into a physical-feeling still. CTA is the constraint, not a feature list.

## Shot outline

| t | Shot |
| --- | --- |
| 0.0–1.4 | Macro grid, pan, no chrome |
| 1.4–3.6 | Pull out; the grid is a phone corner leaving frame |
| 3.6–6.2 | Type behind device: **you never go back** |
| 6.2–10.0 | One photo pushes forward; the rest fall to blur |
| 10.0–13.0 | Full-bleed develop of that photo (real output) |
| 13.0–15.0 | Device partial, product name, true price line |
